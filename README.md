# 📊 Financial & Expense Tracking Analytics Project

An interactive **Power BI Financial Analytics Dashboard** designed to track company revenues, expenses, category-wise budgets, and monthly transaction trends[cite: 1].

---

## 🚀 Project Overview
This project provides a comprehensive financial overview to help stakeholders monitor core financial KPIs in real-time[cite: 1]. It effectively visualizes income streams versus operational expenses using dynamic filtering and clean layouts[cite: 1, 2, 3].

---

## 📈 Key Features & Visuals
* **Revenue vs. Expense KPIs:** High-level summary cards displaying total revenue and expense metrics[cite: 1].
* **Category Breakdown (Pie Chart):** Visualizes transactions and revenue/expense distribution across various categories (e.g., Product Sales, Salaries & Wages, Consulting Services, Marketing)[cite: 1].
* **Budget Allocation (Bar Chart):** Compares allocated budgets across different business categories[cite: 1].
* **Monthly Trends (Column Chart):** Tracks financial volumes month-by-month (January to April)[cite: 1].
* **Interactive Slicers:** Allows users to filter data dynamically by specific categories to analyze precise subsets[cite: 1, 2, 3].

---

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** Used for data visualization, dashboard layout design, and interactive filtering.
* **SQL / Excel:** Used for raw data gathering, structuring, and cleaning (ETL process).
